# 从零理解 AI Agent

剥掉所有框架的包装，一个 Agent 的核心其实是一个循环：

```text
while 没完成:
    想法 = 模型(上下文)
    if 想法.是动作:
        结果 = 执行工具(想法.动作)
        上下文 += 结果
    else:
        return 想法.答案
```

## 三个本质问题

### 1. 它怎么决定下一步？

模型读当前上下文，输出「调用某工具」或「给出答案」。决策质量 = 上下文质量 × 模型能力。

### 2. 它能做什么？

取决于你给的工具集。工具的描述写得好不好，直接决定模型调不调得对。

### 3. 它什么时候停？

停机是被低估的难点。要么模型主动给答案，要么你设步数 / 预算上限兜底，否则它会原地打转。
