# 什么是 MCP

Model Context Protocol（MCP）是一个开放协议，目标只有一个：**让大模型与外部工具、数据源之间的连接标准化**。

## 一个类比

在 MCP 之前，每个应用接每个工具都要写一套私有胶水代码 —— 像各家充电器各用各的接口。MCP 就是那个 **USB-C**：一套标准，两边都按它来，就能即插即用。

## 三个角色

- **Host**：你在用的 AI 应用（如 Claude Desktop、IDE 插件）
- **Client**：Host 内部与服务器通信的连接器
- **Server**：你写的、暴露工具/资源/提示词的程序

## 它能暴露什么

- **Tools**：模型可调用的函数（查数据库、发请求）
- **Resources**：模型可读取的数据（文件、记录）
- **Prompts**：可复用的提示词模板

## 为什么重要

写一次 MCP 服务器，所有支持 MCP 的应用都能用上你的能力。生态的复利就来自这种标准化。
