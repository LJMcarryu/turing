## 1. 目标与范围

### 1.1 目标

把 turing 首页从当前「亮色编辑杂志风」(top-design 约 7/10) 抬升为 **暗黑电影感编辑风** (目标 9.4–9.6/10)，且**不沦为「AI 模板味」**：保留编辑基因（Bodoni、杂志手法、相同信息结构），整体翻到暖调近黑画布 + 电影氛围，并植入**一个封面级签名时刻**。

### 1.2 核心隐喻

> **「一台会思考的机器，刚把这页显影出来」**

冷钴蓝 = 显影液冷光 / 科技；暖琥珀 = 安全灯 / 手作。两色永不渐变、合计面积 < 8%、只在钩子处出现。

### 1.3 本次范围（首页视觉改版）

- **做**：首页全部板块（Cover / Learn / Projects / Blog / Newsletter）的暗黑电影感重设计；暗色 token 系统（`main.css @theme` 暗场覆盖）；Lenis 平滑滚动 + 滚动编排；定制光标；duotone 救图；i18n 标语改动；签名时刻。
- **本次不做（标记为后续）**：404 / empty / loading 暗房状态机；长文 `prose` 暗场重配色与亮场切换的完整实现；其它列表页（/learn、/blog、/projects 列表）的暗场适配；自托管中文 woff2 子集化打包。这些在 §11 列为后续迭代。

### 1.4 已锁定决策

| 项         | 决策                                                                                    |
| ---------- | --------------------------------------------------------------------------------------- |
| 艺术方向   | B — 暗黑电影感编辑风                                                                    |
| 动效程度   | 全套电影级（Lenis 平滑滚动 + 滚动驱动编排/视差）                                        |
| 定制光标   | 要（桌面磁吸/准星，移动端退系统光标）                                                   |
| Cover 标语 | 短标语「以意图，构建机器之思.」/「Build with intent.」，改 i18n；原 16 字标题降为小标签 |
| 卷宗带交互 | 锁滚 + ←/→ 键盘 / 列表视图切换 / 索引逃生口                                             |
| 长文页明度 | 首页/列表暗，长文页（Learn/Blog 详情）提供可选亮场（混合明度）                          |
| 配图色调   | 统一暖琥珀 duotone                                                                      |

> 明度策略说明：上表「首页/列表暗」是**最终态策略**；**本次实现只做首页**（暗场 token 经 `data-theme="noir"` 作用域化），列表页沿用同一机制做 fast-follow，长文页亮场切换列为后续（见 §1.3）。

## 2. 设计概念与签名时刻

### 2.1 唯一封面级签名 =「显影 · 归档」双拍 Cover

**第一拍（载入，约 1.1s）**：暗场里一束程序化聚光 mask 从标题区中心以 `--ease-develop` 阻尼展开（像相纸浸入显影盘浮出影像）；同时 hero 竖图从 grayscale+暗角 经 duotone 显影到位；标题逐字/逐行揭示。**关键**：聚光中心**锚定标题末行的钴蓝句点 `.`**（而非不可控的随机图高光）——它既是聚光几何圆心，又是全场最亮点，光弧绕它收束。这一招同时解决了「咬合靠运气」的风险，并把「标点即活节点」「光弧」缝进同一物件。

**第二拍（交互/可截图静止帧）**：一道 2px 钴蓝光弧（`mix-blend:screen`）穿过巨字字腔，桌面端随鼠标 Y 轴阻尼上下移动；句点每 6s 一次极轻脉冲呼吸。静止截图 = 暖近黑场 + 一行高反差巨字 + 字腔漏出的发光蓝光弧 + 发光蓝句点。移动端：光弧降为首屏静态剪影 + 句点静脉冲。

### 2.2 三处辅助尺度跳变（降为「滚动发现式惊喜」，不与封面争注意力）

1. **Learn**：左侧巨大琥珀描边幽灵编号「01」(14% 描边、overflow-clip、压文字后、避让装订线)。
2. **Projects**：横向**卷宗带 THE REEL**（电影画幅档案卡 + 巨大半透明琥珀 № + 顶部跳数时间码 + 底部走针刻度尺 + 首尾 academy leader 灰场）。
3. **Newsletter**：明度反转——暗房里递出的暖白实体亮卡（偏左 + 四周大黑边 + 卡内 `::selection` 反相）。

## 3. 字体系统

| 角色                   | 字体                                                                                                                     | 关键参数                                                                                                                                                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 英文显示字             | **Bodoni Moda**（已在用，variable opsz 6..96）                                                                           | Cover 巨字 opsz→96、**weight 450 保 didone 纤细**（不提重到 700 钝化），靠 `-0.03em` 负字距 + 极淡 amber-glow `text-shadow:0 0 18px` 补偿暗场可读；line-height 0.9                                                      |

| 正文                   | **Albert Sans**（已在用）                                                                                                | body 16.5px / line-height 1.6 不变                                                                                                                                                                                      |
| 机器层等宽             | **JetBrains Mono**（新增）                                                                                               | meta / kicker / dateline / 图注 Fig. / 时间码 / 帧码；开 `tnum` 防跳。**红线护栏**：机器层小字一律 `--bone` 或 `--cobalt-bright`，**禁用 amber 系**（WCAG 不合格）                                                      |

- **字阶对比**：Cover 巨字 `clamp(3.25rem, 7vw+1rem, 7.5rem)` vs body 1.045rem ≈ **11–12:1**（达「排版即设计」档）。现有 `.mag-1`~`.mag-4` 阶梯保留，仅暗场重定义颜色。
- 中文 dek 不用宋体斜体（难看）→ 改正体 + 钴蓝左竖线。

## 4. 色彩系统（暗场 token）

守住非纯黑红线，60° 暖色相。**实现方式**：在 `main.css` 用 `[data-theme="noir"]`（套在首页根，后续扩展到列表页）覆盖现有 `@theme` 变量，全局亮场默认保持不变，**增量、可回滚**。

### 4.1 画布 / 表面

| Token              | oklch                   | 用途               |
| ------------------ | ----------------------- | ------------------ |
| `--noir`（画布底） | `oklch(0.145 0.014 60)` | 暖近黑「显影液」   |
| `--noir-2`         | `oklch(0.185 0.013 60)` | 卡片 / Projects 区 |
| `--noir-3`         | `oklch(0.225 0.012 62)` | 代码块 / 输入框底  |

### 4.2 文字（反白象牙调，非纯白）

| Token                  | oklch                  | 对比    | 约束                  |
| ---------------------- | ---------------------- | ------- | --------------------- |
| `--bone`（主文/标题）  | `oklch(0.93 0.012 75)` | ≈ 14:1  | —                     |
| `--bone-soft`（次文）  | `oklch(0.74 0.012 72)` | ≈ 7:1   | —                     |
| `--bone-faint`（meta） | `oklch(0.60 0.011 70)` | ≥ 4.5:1 | **仅用于 ≥0.8rem 字** |

### 4.3 分隔线

| Token                              | oklch                  |
| ---------------------------------- | ---------------------- |
| `--rule`                           | `oklch(0.30 0.012 62)` |
| `--rule-soft`                      | `oklch(0.24 0.012 62)` |
| `--rule-strong`（装订线/强调横线） | `oklch(0.45 0.012 62)` |

### 4.4 双语义强调色（永不渐变、合计 < 8%、只在钩子）

| Token             | oklch                  | 语义 / 用途                                                                                                                 |
| ----------------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `--cobalt`        | `oklch(0.62 0.17 258)` | 冷钴蓝=科技/链接/当前项/**句点活节点**/光弧。暗场提亮到 0.62 才「发光」（钴蓝=光，非点缀）。复用现有 token 名，仅暗场重定义 |
| `--cobalt-bright` | `oklch(0.70 0.18 258)` | hover/focus 提亮                                                                                                            |
| `--amber`         | `oklch(0.80 0.135 72)` | 暖琥珀=安全灯/手作/**№ 大编号**/duotone 暖向/loading。**只用于大字与装饰**                                                  |
| `--amber-deep`    | `oklch(0.66 0.13 72)`  | 仅大字/纯装饰，**永不触碰可读小字**                                                                                         |

### 4.5 救图与护栏

- **duotone 救图**：picsum 随机彩图统一叠暖琥珀 `sepia+overlay+contrast` **纯静态 CSS（无动画）**，消杂色、统一进暗场。新增 `.duotone` 工具类。
- **广色域护栏**：`@media (color-gamut: srgb)` 提供降级值，确保暖近黑/钴蓝/琥珀在 sRGB 屏不塌成普通科技蓝黑。

## 6. 动效编排

### 6.1 统一缓动语言（禁 ease/linear）

| 变量             | cubic-bezier                        | 语义                                 |
| ---------------- | ----------------------------------- | ------------------------------------ |
| `--ease-develop` | `cubic-bezier(0.22, 0.61, 0.16, 1)` | 先快后慢沉淀（显影物理）             |
| `--ease-cut`     | `cubic-bezier(0.85, 0, 0.15, 1)`    | 硬切（剪辑）                         |
| `--ease-scrub`   | `cubic-bezier(0.33, 0, 0.07, 1)`    | 走针 / 时间码                        |
| `--ease-reel`    | `cubic-bezier(0.16, 1, 0.3, 1)`     | 揭示（复用仓库现有曲线，落地零成本） |

### 6.2 页面载入时间线（Cover，总 ~1.1s）

```
0ms     暗场 + 静态 SVG 颗粒（mix-blend，单张 tile 非逐帧）淡入
120ms   聚光 mask 以 --ease-develop 绕「句点」展开
260ms   hero 图 grayscale+vignette → duotone 显影（filter 一次性触发，结束即移除 will-change，不阻塞 LCP）
380ms   标题逐字 clip 刷出（英文）/ 整行 translateY 揭示（中文），--ease-reel stagger 40ms
720ms   钴蓝光弧自字下沿扫到上沿、句点点亮并开始 6s 脉冲
1100ms  dispatch 微条 ed-fade 上浮
```

### 6.3 滚动编排（scroll-driven，transform/opacity only）

- 每张图进视口做一次轻显影（**纯 opacity 兜底，非 filter**，护中端 GPU）。
- Projects 卷宗带：滚动驱动横移 + 时间码跳数 + 刻度尺走针。
- **第二结构性时刻**：Cover 被点亮的句点「流」下来，连成 Learn 区的 № 编号锚点——让整页是「一次推理的传播」。

### 6.4 Lenis 配置

`lerp 0.085`（手摇胶卷惯性）、`wheelMultiplier 1`、**`smoothTouch: false`（移动端原生滚动）**。`matchMedia(pointer:fine)` + `prefers-reduced-motion` **双守卫**——reduced-motion 时不挂载 Lenis。实现为 `plugins/*.client.ts`（client-only，SSG 安全）。Lenis ~10KB，懒加载。

## 7. 光标与微交互细节

### 7.1 定制光标（桌面磁吸/准星，移动退系统）

- 全部 `matchMedia(pointer:fine)` 守卫；移动端退系统光标。
- **双层结构**避 `mix-blend:difference` 在极亮/极暗局部反色突兀：difference 主体 + 半透明 1px bone 描边底层。
- **与 hero 聚光做视觉区分**：光标做「走针/取景框对位」细十字准星（非聚光），hover 可交互元素时磁吸吸附 + 准星微张。
- 渐进增强基线：光标特效失败不影响可用性。

### 7.2 品牌化细节（top-design Details 维度做满）

- `::selection` 暗房反相：暗场钴蓝点亮、Newsletter 亮卡内反转。
- hover/focus：链接下划线 `background-size` 从左生长；`focus-visible` 实测 ≥3:1；btn 磁吸。
- 微排版：标题 `text-wrap:balance`、智能引号、`tnum` 数字防跳、`onum` 旧体数字于 № 编号、伪 EXIF 串收编 picsum 占位图。
- 复用现成资产：句点节点（`index.vue:43` 已存在）、`ed-fade`、`bleed-hero` 脚手架、`LevelBadge`、`entry/tile`。

## 10. 无障碍与性能

### 10.1 WCAG 对比（逐 token 钉死）

- `--bone`/`--noir` ≈ 14:1；`--bone-soft` ≈ 7:1；`--bone-faint` ≥ 4.5:1 仅用于 ≥0.8rem。
- `--cobalt` 暗场提亮到 0.62 才用作链接文字，不足处改 `--bone-soft` 下划线保 4.5:1。
- **红线**：amber 系永不用于可读小字（尤其机器层时间码/帧码），只做大字 + 装饰。
- `focus-visible` ≥3:1 实测；`::selection` 明暗场都达标。

### 10.2 `prefers-reduced-motion`（全链路退化）

禁 Lenis、禁聚光 mask 位移、禁光弧/视差/duotone 动画；揭示降 200ms opacity；句点脉冲静止；卷宗带退为可竖滚/可键盘的横向列表；光标退系统。巨字是真实 `h1`（屏读器读完整标语）；光弧/颗粒/幽灵编号 `aria-hidden`。

### 10.3 中文专项验证（双语站硬门槛，**实现期必做、需出真实截图**）

思源宋体在 `clamp` 巨字号 + 暖近黑反白下：实测对比度、横细笔画是否糊、整行揭示是否消除衬线锯齿。据观感定 **weight 600 vs 650** + **是否加轻 amber-glow 描边**。这是 9.4→9.6 的唯一硬门槛，纸面无法拍板。

### 10.4 SSG / 性能契约

纯静态 SSG 友好：颗粒单张静态 SVG tile、duotone 纯静态 CSS、所有动画 `transform/opacity-only`、首屏 hero `eager` 其余 `lazy`。目标 **LCP < 2.5s**（hero 图初始即渲染、filter 只推色不阻塞、结束移除 will-change）、**CLS ≈ 0**、滚动 **60fps**（中端移动降级 30fps 走纯 opacity）。Lenis + 光标 + 卷宗带三者 `matchMedia` + reduced-motion 双守卫，懒挂载。首屏 JS 预算 < 既有基线 + Lenis(~10KB)。

## 12. 验收标准

1. top-design 自评 **≥ 9.4 / 10**（5 维加权）。
2. **签名时刻**在桌面与移动端都成立、可截图。
3. 性能：LCP < 2.5s、CLS ≈ 0、桌面滚动 60fps。
4. 无障碍：WCAG AA 对比全达标；`prefers-reduced-motion` 全链路退化可用；键盘可达（含卷宗带逃生口）。
5. **双语**：中、英文 Cover 各出一张真实截图确认气质一致（§10.3）。
6. 增量安全：暗场 token 作用域限于首页（`data-theme="noir"`），不破坏其它现有亮场页面。
